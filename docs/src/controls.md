# Controls

## Gameplay

| Input | Action |
| --- | --- |
| `W` / `A` / `S` / `D` | Move the shepherd |
| Left mouse drag | Draw a dog route |
| Mouse wheel | Zoom the camera |
| `Esc` | Pause or resume |

## Finish Screen

| Input | Action |
| --- | --- |
| Text keys | Enter highscore name |
| Backspace | Delete the last character |
| `Enter` | Save score, then start a new game |
| `Esc` | Save score and return to menu |

After a score is saved, the highscore list refreshes on the finish overlay and highlights the new entry.
